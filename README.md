Trip Planner is a web-based travel planning application developed using Django, HTML, CSS, and JavaScript. It allows users to explore destinations, view hotel information, and make travel bookings through an easy-to-use interface

FEATURES:

>Browse available travel destinations
>View destination details and prices
>View available hotels and locations
>Book a trip by providing customer details
>Store booking information in the database
>User-friendly and responsive interface
>Django-based backend for handling application logic
>Database integration for destinations, hotels, and bookings


Technologies Used:

Frontend:
HTML
CSS
JavaScrip

Backend:
Python
Django


Database:
SQLite / SQL


How to Run the Project:

1. Clone the repository
git clone <your-github-repository-url>

2. Go to the project directory
cd Trip-Planner

3. Create a virtual environment
python -m venv venv

4. Activate the virtual environment
Windows:
venv\Scripts\activate

5. Install Django
pip install django
If you have a requirements.txt file
pip install -r requirements.txt

6. Apply migrations
python manage.py migrate

7. Run the server
python manage.py runserver

8. Open the application
Open:
http://127.0.0.1:8000/
